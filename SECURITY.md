# Security notes

Do not post Codex credentials, tokens, cookies, authentication files, raw
backend responses, email addresses, or real reset credit IDs in public issues.
Use synthetic data and remove sensitive information from any diagnostic output.

This tool assumes the current operating-system user and the installed Node and
Codex executables are trusted. See [the safety model](docs/safety-model.md) for
account, credit, runtime, and retry safeguards.
